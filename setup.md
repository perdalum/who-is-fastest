# Goal

Have a webpage where one using a nice GUI choses a race and two drivers (by name and team, e.g., drop down or other modern UI elements)  and then a visualization is calculated that for each part of the circuit shows which driver is fastest like on the example visualization.

The project is a personal project and not for deployment nor sharing outside a few people. Use this as a yard stick for the level of robustness and scope.

The product should be a single HTML/CSS/JS page maybe with a few JSON data files. No backend databases should be implemented.
